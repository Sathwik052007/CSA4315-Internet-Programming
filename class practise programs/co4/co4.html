Welcome to Web Services Portal

Web services allow different applications to communicate and exchange information over a network. Java Web Services use technologies such as JAX-RPC, WSDL, SOAP and XML Schema to provide structured communication between client and server applications.

JAX-RPC

Java API for XML-Based Remote Procedure Calls. It allows Java applications to communicate with remote web services.

WSDL

Web Services Description Language describes web service operations, messages and endpoints.

SOAP

Simple Object Access Protocol is used to exchange structured messages between applications.

XML Schema

XML Schema defines the structure, elements and data types of XML documents.

Web Service Architecture

Service Provider

Creates and provides web service operations.

WSDL

Describes the available services and operations.

SOAP

Transfers structured messages between applications.

Service Consumer

Requests and uses the web service.

SOAP Message Structure

SOAP messages are represented using XML. A SOAP message contains an Envelope, Header and Body. The Body contains the actual request or response information.


<soap:Envelope>
  <soap:Header>
  </soap:Header>

  <soap:Body>
    <Add>
      <a>10</a>
      <b>20</b>
    </Add>
  </soap:Body>
</soap:Envelope>

WSDL Description

WSDL provides information about a web service, including its operations, input parameters, output parameters, communication protocol and service address.


<definitions>
  <message name="AddRequest">
    Request Parameters
  </message>

  <message name="AddResponse">
    Response Result
  </message>

  <service name="CalculatorService">
    Calculator Web Service
  </service>
</definitions>

Working Process of Web Services

  1. The service provider creates a web service.
  2. WSDL describes the available service operations.
  3. The client reads the WSDL description.
  4. The client sends a SOAP request.
  5. The server processes the request.
  6. The server returns a SOAP response.
  7. The client receives and displays the result.

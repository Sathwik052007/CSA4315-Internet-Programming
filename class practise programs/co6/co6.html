Welcome to Advanced Web Services

Advanced web services provide communication and integration between different software applications over a network. Technologies such as JAX-RPC, WSDL, SOAP and XML Schema support structured data exchange, service descriptions and remote procedure calls. These technologies help applications communicate independently of their platforms.

JAX-RPC

JAX-RPC enables Java applications to communicate with remote web services through XML-based remote procedure calls.

WSDL

WSDL describes web service operations, input messages, output messages and endpoints.

SOAP

SOAP provides a standard XML-based messaging format for exchanging information between systems.

XML Schema

XML Schema defines the structure, elements, attributes and data types of XML documents.

Advanced Web Service Architecture

Service Provider

Creates and publishes the web service.

WSDL Document

Describes service operations and endpoints.

SOAP Messaging

Transfers XML-based requests and responses.

Service Consumer

Requests and uses the remote service.

XML Data Communication

XML is used to represent structured information exchanged between web service applications. XML Schema validates the structure and data types of the exchanged information.

<Request>
  <Number>5</Number>
</Request>

<Response>
  <Square>25</Square>
</Response>

Working Process of Advanced Web Services

  1. The service provider creates a web service.
  2. WSDL describes the service operations.
  3. The client accesses the service description.
  4. The client sends a SOAP request.
  5. XML Schema defines and validates data structures.
  6. The server processes the requested operation.
  7. The server returns a SOAP response.
  8. The client receives the result.
